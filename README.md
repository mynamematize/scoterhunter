# OLX Scooter Hunter

Стартовый проект Telegram-бота для учёта объявлений о скутерах и расчёта потенциальной прибыли.

## Уже работает
- `/start` — справка
- `/profit покупка продажа ремонт доставка` — оценка прибыли
- `/add URL | цена | ремонт | доставка` — сохранить объявление
- `/latest` — показать последние сохранённые ссылки
- SQLite-хранилище и защита от повторного сохранения одного URL

## Пока не реализовано
Автоматический мониторинг OLX. Файл `sources.py` — адаптер-заготовка. Перед подключением автоматического сбора необходимо проверить актуальные правила OLX и доступность разрешённого источника данных. Бот не должен выдавать демонстрационные данные за реальные объявления.

## Установка (macOS / Linux)
Требуется Python 3.10+.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Открой `.env`, вставь токен Telegram-бота, созданного через `@BotFather`, затем запусти:

```bash
python bot.py
```

## Примеры команд
```text
/profit 5000 8000 1000 300
/add https://www.olx.ua/ | 5000 | 1000 | 300
/latest
```

## Настройки стратегии
Для первой версии целевые настройки: Львовская область, без фиксированного бюджета, желаемая чистая прибыль от 1500 грн. Сейчас регион и прибыль отображаются как стартовые настройки; автоматический региональный фильтр заработает после подключения источника объявлений и нормализации географии.
